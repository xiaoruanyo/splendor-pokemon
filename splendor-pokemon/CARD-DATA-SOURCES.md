# 基础版牌表来源与核对

更新时间：2026-09-08。

## 结论与边界

已将原项目自定义牌表替换为 90 张基础版社区转录数据：一阶 35、二阶 30、三阶 15、稀有 5、传说 5。所有进化条件均为单色永久奖励数量。包含同一种宝可梦的不同捕获费用版本。

尚未找到出版社直接发布、可逐张验证的完整机器可读牌表。此次采用的两个社区项目，其 90 张基础牌的费用、分数、奖励、进化目标与进化条件全部吻合，但不能因此宣称得到官方认证，也不能确认两者上游完全独立。没有对 90 张实体原卡逐张目视核验。不要在产品或文档中将其称为“官方发布的数据”。

## 固定来源

1. [社区牌表转录](https://github.com/LeonJoeeee/splendor-pokemon/blob/c4a0a4fe564483d9568a0a436367400a090f9657/src/data/cards.ts)，提交 c4a0a4fe564483d9568a0a436367400a090f9657。该项目注明来自社区 CSV 转录，数值仍待实体卡核对。
2. [卡图提取牌表](https://github.com/Ethan9123/pokemon-splendor/blob/3c29be1a58f5b4438b2d90e4a7850cff423ab200/data/cards.json)，提交 3c29be1a58f5b4438b2d90e4a7850cff423ab200。该项目注明从 TTS 中文自制卡面识别并复核；其中额外 10 张社区特殊牌未引入。
3. [规则民间英译](https://www.scribd.com/document/919166914/PokemonSplendor-English-Rulebook-Bifold-Print-v1-1)：用于核对牌数、进化检查永久奖励、替换旧卡分数以及特殊牌的大师球要求。
4. [实体版玩家进化分类](https://note.com/sirei/n/n3b7134288991)：用于核对进化数量和各阶分数分布。
5. [中国发行商公告](https://oo-h.asmodee.com.cn/en_US/blog/news-1/post/237)：确认授权产品存在；该公告并不提供完整牌表。

只转换牌表事实数据，没有复制参考项目的游戏实现或卡面美术。缺失的 18 张宝可梦插画沿用本项目既有 PokéAPI sprites 来源。

## 数据映射

- 源表的进化条件印在进化前的宝可梦上；当前引擎把同一条件存到目标卡的 `evolutionReq`，并用 `evolutionOf` 指向前置宝可梦。转换时验证同物种的费用变体具有相同进化条件。
- 源表 `master` 映射到本项目 `purple`，普通球颜色不变。
- 妙蛙种子 → 妙蛙草：粉色永久奖励 3；妙蛙草 → 妙蛙花：蓝色永久奖励 4。
- 稀有牌 0 分、传说牌 2 分，均提供两个普通色永久奖励且费用含 1 个大师球。
- 本地与服务端 `cardDefinitions.ts` 保持完全一致，回归测试检查一致性。

## 验证与运行

运行 `node scripts/test-card-data.cjs` 检查全部牌的数量、唯一 ID、图片、单色进化条件、前置物种、双端一致性，以及大师球支付和进化后的分数替换。前端生产构建、桌面和手机翻面测试通过。尚未进行真实联网后端集成测试。

刷新后重新开局才能使用新牌表，已经发出的旧牌局不会自动迁移；联机服务需重启并创建新对局。
